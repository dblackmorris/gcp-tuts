# Google Cloud Platform 
Basic Commands and use cases on GCP are describe on this repo.
## gsutil
A python application that provide access cloud storage command line. Find related commands in **gsutil.sh** file.

## GitHub Actions OIDC proof of concept

Authenticate GitHub Actions to Google Cloud without service account keys using
Workload Identity Federation. See [the setup and usage guide](oidc/README.md) for
the provisioning script, manual workflow, and optional Cloud Storage access check.
